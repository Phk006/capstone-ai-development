\## Development Conventions



\- Use TypeScript wherever possible.

\- Keep the project structure clean and modular.

\- Create reusable components.

\- Use meaningful variable and function names.

\- Avoid unnecessary dependencies.

\- Keep code readable and maintainable.

\- Do not modify unrelated files.

\- Check for errors after making changes.



\## Git Conventions



Use Conventional Commits.



Examples:



\- feat: add authentication

\- fix: resolve validation issue

\- docs: update README

\- refactor: simplify API structure

\- chore: update dependencies



\## AI Assistant Rules



Before making significant changes:



1\. Understand the existing project structure.

2\. Explain the proposed approach.

3\. Make the smallest necessary changes.

4\. Check for errors after implementation.

5\. Summarize what was changed.
